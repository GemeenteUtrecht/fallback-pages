# Fallback Pages

Deze repository bevat statische fallbackpagina’s voor onze website en het digitaal loket.

De pagina’s worden gebruikt wanneer de reguliere website of het digitaal loket tijdelijk niet beschikbaar is, bijvoorbeeld door een storing, onderhoud of uitval van onderliggende systemen.

## Doel

Het doel van deze repository is om een centrale plek te bieden voor tijdelijke “sorry-pagina’s” die:

- snel inzetbaar zijn bij verstoringen
- eenvoudig te hosten zijn als statische pagina
- duidelijke informatie geven aan bezoekers
- gebruikt kunnen worden voor zowel de website als het digitaal loket

## Inhoud

Deze repository bevat onder andere:

- `index.html` – de standaard fallbackpagina
- eventuele varianten voor:
  - website
  - digitaal loket
  - gepland onderhoud
  - onverwachte storing

## Gebruik

Wanneer de website of het digitaal loket niet beschikbaar is, kan vanuit de fallback-locatie tijdelijk een statische pagina uit deze repository worden geserveerd.

De pagina toont bezoekers een korte uitleg en kan waar nodig verwijzen naar:

- wat werkt er nog wel
- een telefoonnummer
- een e-mailadres
- een andere beschikbare contactmogelijkheid

## Uitgangspunten

De fallbackpagina’s in deze repository zijn:

- statisch en lichtgewicht
- snel te deployen
- eenvoudig te beheren
- toegankelijk en duidelijk geschreven
- onafhankelijk van backend-systemen

## Beheer

Aanpassingen aan teksten, contactgegevens of styling kunnen in deze repository worden bijgehouden, zodat altijd een actuele versie beschikbaar is voor inzet bij incidenten of onderhoud.

## Opmerking

Deze repository is bedoeld als noodvoorziening en niet als vervanging van de reguliere website of het digitale loket.
